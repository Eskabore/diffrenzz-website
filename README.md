# Diffrenzz Website 🌐

This is the official website for **Diffrenzz**, a freelance Salesforce development and consulting business.

Built with:
- ⚛️ React
- 🎨 TailwindCSS
- ⚡️ Vite
- 🚀 Hosted on Netlify/Vercel

## 📦 Setup

```bash
npm install
npm run dev
```

## 🌍 Internationalization

Translations use **react-i18next** with English as the fallback language. Use the header's language selector to switch languages.

## 🔨 Build

Create an optimized production build:

```bash
npm run build
```
